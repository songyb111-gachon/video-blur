영상 속 사람과 얼굴을 블러나 모자이크로 가리는 앱입니다. 아래 파일 하나만 받으면 됩니다.

## 시작하기

- **윈도우**: `video-blur-windows.bat`을 받아 더블클릭합니다. 내려받은 파일이라 윈도우가 경고를 띄우면 "추가 정보"를 누른 뒤 "실행"을 고릅니다.
- **macOS, 리눅스**: `video-blur-mac-linux.sh`를 받아 터미널에서 `sh video-blur-mac-linux.sh`를 실행합니다.

처음 실행하면 없는 것을 스스로 설치한 뒤 브라우저에 앱을 엽니다. 인터넷 연결이 필요하고 몇 분 걸립니다. 다음부터는 같은 파일을 다시 실행하면 바로 켜집니다.

## 설치되는 것

| 무엇 | 어디에 |
|---|---|
| 앱 | 윈도우 `%LocalAppData%\video-blur`, macOS·리눅스 `~/.local/share/video-blur` |
| Python (없을 때) | 윈도우는 winget, macOS는 Homebrew, 리눅스는 시스템 패키지 관리자로 PC에 설치 |
| 파이썬 패키지 | 앱 폴더의 `.venv` |
| ffmpeg (없을 때) | 윈도우는 winget, 없으면 앱 폴더의 `tools`에 내려받음. macOS는 Homebrew, 리눅스는 시스템 패키지 관리자 |
| 모델 파일 | 해당 방식을 처음 쓸 때 사용자 폴더의 `.cache/vblur` |

지우려면 앱 폴더를 지웁니다. 올린 영상과 결과도 그 안에 있습니다.

## 알아 둘 점

- 빠짐없이 가려진다는 보장은 없습니다. 공개하기 전에 결과 영상을 직접 재생해 확인하세요.
- 메모리는 8GB 이상을 권합니다.
- 앱과 macOS·리눅스용 시작 파일은 리눅스에서 시험했습니다. 윈도우용 시작 파일은 아직 윈도우에서 실행해 보지 못했습니다.
